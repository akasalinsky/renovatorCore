# RenovatorCore

Этот проект представляет собой Java-приложение для расчета строительных материалов, необходимых для ремонта помещений. Он включает в себя классы для моделирования недвижимости (`Property`), комнат (`Room`) и выполнения расчетов для различных видов ремонтных работ (обои, грунтовка, напольные и потолочные покрытия).

## Структура проекта

*   **`/src/main/java/org/example/model`**: Содержит модели данных:
    *   `Property.java`: Представляет объект недвижимости (квартиру, дом) с набором комнат.
    *   `Room.java`: Представляет отдельную комнату с ее размерами и площадью проемов.
*   **`/src/main/java/org/example/actions`**: Содержит классы, выполняющие расчеты:
    *   `Wallpaper.java`: Расчет количества рулонов обоев.
    *   `Primer.java`: Расчет необходимого количества грунтовки.
    *   `FloorCaverings.java`: Расчет площади пола.
    *   `Cellings.java`: Расчет площади потолка.
*   **`/src/test/java`**: Содержит юнит-тесты для проверки корректности расчетов.
*   **`pom.xml`**: Файл конфигурации Maven, определяющий зависимости проекта (включая JUnit) и сборку.

## Как использовать

1.  **Сборка проекта:**
    ```bash
    mvn clean package
    ```
2.  **Запуск основного метода (демонстрация):**
    Пример запуска находится в `src/main/java/org/example/Main.java`. Вы можете выполнить его через вашу IDE или с помощью Maven:
    ```bash
    mvn exec:java -Dexec.mainClass="org.example.Main"
    ```
    *Примечание: Убедитесь, что в `pom.xml` настроен плагин `exec-maven-plugin`, если вы хотите запускать `Main` таким образом.*

## Юнит-тестирование

Проект включает юнит-тесты для проверки корректности расчетов.

1.  **Запуск тестов:**
    ```bash
    mvn clean test
    ```

## Зависимости
