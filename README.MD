# Room Planner (учебный TDD-проект на Java)

Приложение для расчёта характеристик комнаты: площади стен, объёма, количества обоев и т.д.  
Разрабатывается с использованием **Test-Driven Development (TDD)** и AI-ассистента.

## 🧠 Цели проекта

- Освоить классический TDD (красный → зелёный → рефакторинг) на практике.
- Научиться проектировать иммутабельную предметную модель с помощью тестов.
- Получить опыт написания тестируемого кода и рефакторинга с сохранением работоспособности.
- Создать основу для будущего Telegram-бота.

## 📦 Текущее состояние

- ✅ Иммутабельная модель комнаты (`Room`) с размерами и проёмами.
- ✅ Класс проёма (`Opening`) с поддержкой разных типов (окно, дверь, общая площадь).
- ✅ Вычисление площади пола, объёма, общей и полезной площади стен.
- ✅ Расчёт количества рулонов обоев.
- ✅ Удобный метод `describe()` для получения сводки о комнате.
- ✅ Более 20 модульных тестов (JUnit 5 + AssertJ), покрывающих все основные сценарии.
- 🚧 В будущем: класс `Wall`, поддержка комнат сложной формы, интеграция с Telegram-ботом.

## 🛠 Технологии

- Java 17+
- JUnit 5 (Jupiter)
- AssertJ
- Maven– управление зависимостями
- Git для контроля версий
