# Тестовое описание квартиры для юнит-тестов

## Адрес:
Ул. Ремонтная, д. 1, кв. 10

## Общая информация:
Квартира состоит из трех комнат и кухни-гостиной. Высота потолков во всех помещениях – 2.8 метра.

## Комнаты:

### 1. Гостиная
*   **Размеры:** Длина - 5.5 м, Ширина - 4.2 м
*   **Проемы:** Одно большое окно (площадью 3.0 м²) и дверной проем (площадью 2.1 м²)
*   **Назначение:** Зона отдыха, просмотра ТВ.

### 2. Спальня
*   **Размеры:** Длина - 4.0 м, Ширина - 3.0 м
*   **Проемы:** Одно стандартное окно (площадью 1.5 м²)
*   **Назначение:** Зона для сна.

### 3. Детская комната
*   **Размеры:** Длина - 3.5 м, Ширина - 3.0 м
*   **Проемы:** Дверной проем (площадью 2.0 м²)
*   **Назначение:** Комната для ребенка.

### 4. Кухня-гостиная
*   **Размеры:** Длина - 6.0 м, Ширина - 4.5 м
*   **Проемы:** Два дверных проема (по 2.1 м² каждый)
*   **Назначение:** Зона приготовления пищи и обеденная зона.

## Дополнительные замечания:
*   Площадь проемов (окна, двери) должна вычитаться из общей площади стен при расчете материалов для стен (обои, грунтовка).
*   Площадь пола и потолка рассчитывается отдельно для каждой комнаты.

---

## Описание тестов

В проекте реализованы юнит-тесты с использованием JUnit 5 для проверки корректности расчетов.

### Тесты для `Room.java` (`src/test/java/org/example/model/RoomTest.java`)

*   `testGetTotalWallArea()`: Проверяет расчет общей площади стен комнаты.
*   `testGetNetWallArea()`: Проверяет расчет чистой площади стен (с учетом проемов).
*   `testGetFloorArea()`: Проверяет расчет площади пола.
*   `testGetRoomName()`: Проверяет корректность получения имени комнаты.
*   `testGetRoomLength()`: Проверяет получение длины комнаты.
*   `testGetRoomWidth()`: Проверяет получение ширины комнаты.

### Тесты для `Wallpaper.java` (`src/test/java/org/example/actions/WallpaperTest.java`)

*   `testWallpaperCalculationForLivingRoom()`: Проверяет расчет количества полос обоев для Гостиной.
*   `testWallpaperCalculationForBedroom()`: Проверяет расчет количества полос обоев для Спальни.

### Тесты для `Primer.java` (`src/test/java/org/example/actions/PrimerTest.java`)

*   `testPrimerCalculationForLivingRoom()`: Проверяет расчет литров грунтовки для Гостиной.
*   `testPrimerCalculationForBedroom()`: Проверяет расчет литров грунтовки для Спальни.

### Тесты для `FloorCaverings.java` (`src/test/java/org/example/actions/FloorCaveringsTest.java`)

*   `testFloorCalculationForLivingRoom()`: Проверяет расчет площади пола для Гостиной.
*   `testFloorCalculationForKitchen()`: Проверяет расчет площади пола для Кухни-гостиной.

### Тесты для `Cellings.java` (`src/test/java/org/example/actions/CellingsTest.java`)

*   `testCellingCalculationForLivingRoom()`: Проверяет расчет площади потолка для Гостиной.
*   `testCellingCalculationForKitchen()`: Проверяет расчет площади потолка для Кухни-гостиной.
